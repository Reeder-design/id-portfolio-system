Visual Language

Iconography, identity, and motion

A personal L&D visual system designed to make the portfolio recognizable, technical, and human without competing with the work itself.

Usage rules Icon library Portfolio mark Motion

Direction

Visual rules

The icon system supports the portfolio hierarchy; it does not replace meaningful content or become decoration for decoration's sake.

Icon first

Use icons to replace repetitive decorative copy, especially in right-side hero visuals. Important information stays in the primary content column.

Soft geometry

Rounded squares, circles, connected nodes, fine lines, translucent surfaces, and restrained gradients create the shared systems-oriented language.

Purposeful motion

Use small reveals, hover lift, and slow ambient movement to reinforce hierarchy. Content never depends on animation, and reduced-motion preferences are honored.

Library

Portfolio icons

The reusable SVG sprite lives at portfolio/assets/icons/portfolio-icons.svg. Icons inherit currentColor, allowing one source asset to work across heroes, cards, interactions, and project pages.

Identity

Portfolio mark / favicon

Connected learning → useful outcome

The mark combines a simple path, connected nodes, and a small spark. It represents the through-line of the portfolio: connect the pieces, reduce complexity, and design toward a usable outcome.

Behavior

Motion language

Motion should make hierarchy and interaction feel more intentional, never make the page harder to read.

Reveal

Small vertical movement and fade as sections enter the viewport. Content remains fully usable without JavaScript.

Ambient

Slow decorative movement or parallax belongs on non-reading elements only.

Interaction

2–5px hover lift, clearer borders, short transitions, and visible keyboard focus for interactive elements.
