Direction

Visual rules

Icon first

Use icons to replace repetitive decorative copy, especially in right-side hero visuals. Important information remains in the primary content column.

Soft geometry

Rounded squares, circles, connected nodes, fine lines, and restrained gradients create a systems-oriented visual language without looking like a software dashboard.

Purposeful motion

Use small reveals, hover lift, and slow ambient movement to reinforce hierarchy. Never make content depend on animation, and honor reduced-motion preferences.

Library

Portfolio icons

The SVG sprite lives at portfolio/assets/icons/portfolio-icons.svg. Icons inherit currentColor, so one source asset works across cards, hero graphics, interactions, and future project pages.

Identity

Portfolio mark / favicon

Connected learning → useful outcome

The mark combines a simple path, connected nodes, and a small spark. It represents the through-line of the portfolio: connect the pieces, reduce complexity, and design toward a usable outcome.

Behavior

Motion language

Reveal

Small vertical movement + fade as sections enter the viewport. Content is fully visible when JavaScript is unavailable.

Ambient

Slow ring rotation and minimal parallax on decorative elements only. Never apply it to reading content.

Interaction

2–5px hover lift, clearer borders, and short transitions for buttons/cards. Focus states remain keyboard-visible.
