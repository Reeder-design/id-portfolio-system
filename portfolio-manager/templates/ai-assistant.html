When to use this

Supporting work, not the main creation flow

Use the Content Lab for a new project

The guided brief keeps purpose, audience, story, evidence, interactions, visual direction, and safety constraints together before AI planning.

Use this helper for one task

Good fits include polishing a draft, analyzing a document, reviewing a screenshot, checking placement, inspecting code, or drafting a short project summary.

Uploads stay private until approval

Files are first stored only in the Git-ignored local workspace. Document/code text is extracted locally. The external request happens only after the prepared review and acknowledgements.

Images need extra judgment

The full image is sent as visual input after approval. Local preflight checks the prepared text for common markers, but it does not inspect pixels, screenshots, logos, names, or metadata visible inside images.

Evidence rule

The assistant is instructed not to invent metrics, tools, accomplishments, clients, products, or outcomes that are not supported by your source.
