How to use this

Reuse the pattern, not a copied page

A component record tells you what problem the pattern solves and which files own the implementation. Recording a component on a project documents the design system; it does not inject markup into a custom page. Standard renderer components are clearly labeled when the shared project template already knows how to build them.
