Simple publishing boundary

Commit and publish are separate actions.

Commit Changes creates a validated local checkpoint on main. Publish to GitHub is the separate action that pushes those committed changes to origin/main, where GitHub Pages can deploy them. Force-push is not available, and private Portfolio Manager files cannot be staged.
