Overview

Evaluation starts with requirements and evidence

A polished response can still be inaccurate, incomplete, unsupported, or misaligned with the task.

I define the task, audience, source material, and success criteria before evaluating accuracy, completeness, instruction adherence, consistency, and usability.

I separate material quality issues from stylistic preference and focus feedback on problems that affect correctness, usefulness, or reliability.

Evaluation Context

Define what success means before judging the output.

I identify the task, audience, required source material, constraints, and expected deliverable so the review is anchored to the actual assignment.

Review question

What was the model actually asked to do?

Common failure

Scoring fluency or personal preference instead of requirement coverage.

Evidence

Prompt, source materials, rubric, reference answer, user goal, and explicit constraints.
