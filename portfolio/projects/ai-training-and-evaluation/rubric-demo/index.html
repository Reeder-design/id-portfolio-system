AI Evaluation Rubric

A public-safe example of how I use clear review areas and score anchors to make AI evaluation more consistent and explainable.

Review area + score + calibration

What This Is

A rubric calibration exercise.

This demo uses one fictional response and looks at one quality area at a time. The task, approved source, and model output stay the same so you can see how a different review lens changes the judgment.

How to Use It

Read the packet, choose a review area, then score it.

Use the packet tabs to review the task, source, and model response. Select one text-and-source metric, choose the 0 to 3 anchor that best fits, and reveal the benchmark to compare your score and reasoning.
