What This Is

A visual QA pipeline.

This demo shows how one review case moves from the original assignment through evidence checking, issue diagnosis, and calibration. Each stage creates a clear artifact that the next stage can use.

How to Use It

Move the case through the pipeline.

Select any stage on the pipeline. The case packet moves to that station, the stage details update below it, and the artifact belt shows what has already been created and what the current stage produces.
