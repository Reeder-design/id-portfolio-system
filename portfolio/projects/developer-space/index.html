03 / Code Block Composer

A visual workspace for interactive learning blocks.

I use Code Block Composer to create learning blocks from a blank canvas or template and to edit supported parts of imported HTML and ZIP packages. The editor brings content, media, interactions, and motion into one workspace, then carries the finished block through accessibility review and a self-contained export.

  • In-context editing for text, images, buttons, tabs, and layers
  • Desktop, tablet, and phone previews of the learner experience
  • Saved projects, review snapshots, and packaged block exports
