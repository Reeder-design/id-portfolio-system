My L&D Work

From the learning need to the learning ecosystem.

I don't think of instructional design as simply creating courses. The work starts with understanding the learner, the performance need, and the business problem before deciding what kind of learning solution actually makes sense.

Depending on the need, that solution might be a focused interaction, multimedia training asset, assessment experience, certification pathway, or a larger learning ecosystem connecting content, LMS delivery, tracking, and reporting.

The Learning Lifecycle

I think beyond the individual asset.

Whether I'm creating one interaction or a complete learning pathway, I use the same basic logic: understand the need, design the right solution, build it well, deliver it effectively, and create feedback loops that help improve it.

1

Identify the Need

Clarify the audience, performance gap, business need, constraints, and what the learner actually needs to be able to do.

2

Design the Solution

Determine the right learning architecture, objectives, content, practice, assessment, and delivery approach.

3

Develop the Experience

Build the learning assets, interactions, multimedia, assessments, resources, and supporting content.

4

Deliver + Support

Structure the learner experience through the LMS, pathways, certification rules, communications, and supporting systems.

5

Measure + Improve

Use assessment results, completion data, learner feedback, QA findings, and reporting to improve the learning over time.
