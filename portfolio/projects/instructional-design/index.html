Instructional Design

I design learning from needs analysis through launch and maintenance. Depending on the problem, that can mean eLearning, multimedia, interactive practice, microlearning, live facilitation, assessments, or performance tools.

Needs AnalysisLearning ArchitectureDevelopmentQAMeasurement + Updates

Design Approach

Different learning products need different design workflows.

I start with the performance need, audience, source content, constraints, and how the learner will use the solution. Then I choose the format and level of build effort that fit the job.

The work changes by deliverable, but I keep the same closed loop: define the design philosophy, plan the experience, build it efficiently, and make sure feedback, ownership, and updates are part of the solution.

eLearning

Close the loop from performance need to future updates.

I build eLearning so objectives, practice, assessment, delivery, and maintenance all point to the same performance outcome instead of becoming separate pieces of work.

Audience fitObjective alignmentMaintainability
Philosophy

Do not waste the learner's time. Start with the performance need, keep the content relevant, and make every activity earn its place.

Design

Define the audience, objectives, outcomes, source-content and asset library, approval path, storyboard, scripts, prompts, practice, and assessment plan before development gets expensive.

Development

Use reusable patterns, strong authoring practices, accessibility, QA, and structured SME review so development stays efficient without flattening the learner experience.

Full Circle

Tie assessments back to objectives, keep source files and templates editable, document ownership, collect feedback and analytics, and plan how the learning will be updated after launch.
