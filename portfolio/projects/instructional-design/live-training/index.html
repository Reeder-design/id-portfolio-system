Content Development

Build materials that help a facilitator teach, not just present.

I create live-training content for virtual or in-person delivery, including the structure, materials, practice, and facilitator guidance needed to run the session consistently.

Structure the session

Define objectives, agenda, pacing, transitions, activities, and debriefs around what learners need to do.

Build the materials

Create presentation content, facilitator notes, participant resources, polls, prompts, handouts, and shared references.

Add practice

Use discussion, scenarios, activities, and guided questions so live time is used for application instead of slide narration.

Prepare for delivery

Document timing, instructions, transitions, resources, and contingency notes so another facilitator can run the session.
