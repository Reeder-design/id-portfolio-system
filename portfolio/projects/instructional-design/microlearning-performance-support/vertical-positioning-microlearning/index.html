The Need

The original scope combined too much industry context for a short learning asset.

Sellers needed enough context to understand each operating environment and recognize relevant use cases, but the combined topic created too much switching between industries. I split the work instead of forcing both settings into one course.

Industry context

Each module needed enough operating context for the use cases to feel credible.
