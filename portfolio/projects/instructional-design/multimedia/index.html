Production Workflow

From learner need to release-ready media.

One illustrative brief moves through four checkpoints: define the learner decision, compose the message, correct quality issues, and test the result in context. The same checkpoints apply across still, moving, narrated, and generated media.

ILLUSTRATIVE LEARNING BRIEFHelp a learner choose a useful response when a customer asks for more time.Recognize the cue → decide what to do next

01 / FRAME THE MOMENT

Define the decision the learner must make.

I identify the cue the learner needs to notice, the response they need to choose, and the approved source behind it. I set audience, placement, duration, and accessibility needs before choosing a format.

Decision

What needs to be seen, heard, or practiced for the learner to choose well?

Artifact

A media brief with source boundaries, content beats, and the intended learner action.

Evidence

A reviewer can trace each beat to the learning goal and approved content.

Across formats

A still may need a clear reading path; timed media needs pacing; generated visuals need an explicit accuracy boundary.
