01

Need

The same reporting package required four manual LMS report pulls.

The process was repetitive, but the completion logic still needed to stay visible. The automation needed to save browser and spreadsheet work without hiding missing matches or unusual records.

Recurring inputs

Four saved LMS reports covering employee and partner course activity and certificate records.

Required output

A workbook that separated Complete and Incomplete learners, included user type, and kept exceptions available for review.

02

Reporting Logic

I automated the repeatable steps and kept the review points visible.

Browser automation

Selenium opened the saved LMS reports, generated each report, and downloaded the Excel exports in a consistent sequence.

Data comparison

I used username as the learner key, normalized the exported data, compared activity and certificate records, and surfaced unmatched or unexpected records instead of discarding them.

03

Build

Python handled the report package from download through workbook creation.

Selenium handled the browser work. pandas read and normalized the exports. openpyxl created the final Excel workbook and organized the review sheets.

Automation stack

PythonSeleniumpandasopenpyxlExcelAbsorb LMS

Checks I kept

Expected filenames, missing downloads, duplicate or unmatched learner records, unexpected completion states, and user type remained visible for review.

04

Output

A repeatable reporting package that was easier to review.

  • Automated generation and download of four recurring LMS reports.
  • Replaced manual comparison across exports with Complete and Incomplete worksheets.
  • Included learner type in the final review output.
  • Kept exceptions visible so the final status could still be checked before use.
