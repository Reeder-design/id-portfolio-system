Inside the Intelligence Hub.

I organize market intelligence around the evidence behind a finding. A source, an observation, a trend, and an implication answer different questions; the relationships between them make the analysis traceable.

Keep the cited item intact.

The source record identifies the exact document, recording, page, or report behind the finding. The source and the place it was found are separate, so a portal name never substitutes for evidence.

Source context
Title, format, location, and access context.
Design decision
One cited item can support multiple observations without being copied into each record.
